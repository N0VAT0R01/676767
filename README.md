# 🎓 КнАГУ — День первокурсника

Небольшая образовательная браузерная игра в формате студенческого квеста.

## Возможности

- 🎓 игровой день первокурсника;
- ⭐ очки и бонус за серию правильных ответов;
- ❤️ три жизни;
- 🧩 несколько мини-игр;
- 📚 образовательные вопросы;
- 🧠 игра на память;
- ⚡ проверка реакции;
- 🔢 запоминание числовой последовательности;
- 🏆 четыре ранга;
- 💾 лучший результат сохраняется в браузере;
- 📱 адаптивный дизайн;
- 🏛️ эмблема КнАГУ добавлена в интерфейс;
- 🚀 не требует сервера, базы данных или сборщика.

## Мини-игры

1. Вопрос с вариантами ответа.
2. Логическая последовательность.
3. Игра «Память».
4. Быстрая реакция.
5. Запоминание числового кода.

## Запуск

Просто открой `index.html` в браузере.

## GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи `index.html`, `style.css`, `script.js`, `README.md` и папку `assets`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Нажми **Save**.
6. Через некоторое время GitHub Pages выдаст адрес сайта.

## Использование эмблемы

В проект добавлена предоставленная эмблема КнАГУ (`assets/knagu-logo.jpg`) на основании разрешения пользователя на её использование. Не распространяйте эту версию проекта за пределами предоставленного разрешения.
